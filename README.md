# rust-dsp-web

Browser front-end for the [rust-dsp](https://github.com/pierreportal/rust-dsp)
modular synthesizer. A React + `@xyflow/react` patch-design canvas that runs the
Rust DSP graph compiled to WebAssembly inside an AudioWorklet on the audio
thread.

The module catalogue (kind codes, ports, parameters) is **generated by the Rust
crate** and shipped as `pkg/module-registry.json`. The UI builds itself against
whatever DSP release is pinned, so new Rust modules appear in the palette
without any TypeScript changes.

## Architecture

- `src/` — React UI (main thread): owns the patch graph state, mirrors mutations
  to the worklet via `audioEngine`.
- `public/graph-processor.js` — AudioWorklet processor that owns the wasm
  `Graph` and renders audio.
- `public/textdecoder-polyfill.js` — codec polyfill needed by the worklet scope.
- `pkg/` — wasm bundle + `module-registry.json`, **downloaded** by
  `scripts/fetch-dsp.sh` from a rust-dsp GitHub release (gitignored).
- `scripts/fetch-dsp.sh` — downloads the wasm pkg from the pinned rust-dsp
  release into `pkg/`.

## Deployed to Netlify

`netlify.toml` builds on Netlify:

1. `scripts/fetch-dsp.sh` downloads the pinned rust-dsp release.
2. `npm ci && npm run build` produces a static `dist/`.

To target a specific DSP release set the `DSP_VERSION` build env (e.g.
`web-v0.1.0`); it defaults to the latest rust-dsp web release.

## Local development

1. Build the DSP pkg (from a rust-dsp checkout) or fetch an existing release:

   ```bash
   # from a rust-dsp checkout:
   cd web && ./scripts/build-dsp.sh
   # copy the result into this repo:
   cp -R /path/to/rust_dsp/web/pkg ./pkg
   # --- or --- download from GitHub releases:
   ./scripts/fetch-dsp.sh web-v0.1.0
   ```

2. Install deps and run Vite:

   ```bash
   npm install
   npm run dev
   ```

   Node 18+ is required (see `.nvmrc`).

## Releasing a new DSP module

See [`docs/adding-a-module.md`](docs/adding-a-module.md) for the full
walk-through. In short:

1. Add the module in the `rust-dsp` repo (`web/src/graph.rs` + the registry in
   `web/src/registry.rs`), rebuild the pkg with `scripts/build-dsp.sh --release`,
   and copy `web/pkg/` into this repo's `pkg/`.
2. Publish a `web-vX.Y.Z` tag on rust-dsp → its release workflow builds the pkg
   + registry and attaches `rust-dsp-pkg.tar.gz`.
3. Deploy this repo with `DSP_VERSION=web-vX.Y.Z` → users get the new module.
